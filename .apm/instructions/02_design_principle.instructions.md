# 设计规范

请遵循以下规范，设计现代、合理的用户界面。

1. 设计组件前，请你回想：同类功能在成熟现代应用中的具体设计（e.g. 导航 / 筛选 / 设置表单 / 仪表盘等）。
2. 站在巨人肩膀上，编写成熟、完整的组件。除非用户明确表示输出简化版原型，必须以同类应用的最佳现代体验为标准，不要输出懒惰、简化、占位的设计。
3. 编写文案前，设想：如果是 Apple 会如何表达？注意做减法：不是所有主题都需要描述块，不是所有设计选择都需要用户了解（禁止将开发中的提示词或文档直接用作文案）。从用户界面出发编写文案，清晰传达用户需知的信息。
4. 使用图标库 和 Design Token。绝大多数情况下，不应硬编码颜色值或手写图标。
5. 追求 Hand-crafted 而现代的设计。避免 AI Slop 风格。
  - 禁止深色霓虹风格
  - 禁止滥用 Emoji
  - 禁止在文案内复述提示词或计划文档
  - 禁止滥用形如“Chinese（English）”的双语标注

# cross-check

使用下面的提示词启动 `expert` 子代理。

```
请中立、客观地核查以下想法 / 结论 / 计划 / 决策：

<待检查内容>

工作要求：

1. 深入检查预设（即使看似已成定论）；设计（是否其实有更优的替代方案）；逻辑（是否有错误的/不充分的推论）；权衡（是否高估或低估了利弊）；失败模式（是否忽略或夸大了风险因素）。
2. 探索相关文件，主动获取需要的信息。对于依赖外部事实、API 或行业实践的断言，进行深入的网络调研。
3. 关注真正有害的思维误区和盲点，而非吹毛求疵或过度设计。

输出格式：

## Must Reconsider

- （必须重新审视的内容。注明影响、参考资料、建议行动。若无则跳过。）

## Suggestions

- （非阻塞性建议。若无则跳过。）

## Open questions

- （开放性讨论。若无则跳过。）
```

根据核查结果重新整理思路，调整下一步行动。如方向有重大变更，先请用户确认。

# grilling

就当前计划对我进行刨根问底的追问，直到我们达成共识。遍历设计树的每个分支，逐条化解决策之间的依赖关系。每个问题同时提供你的推荐答案。

一次只问一个问题，等待反馈后再继续。一次性问多个问题会让人困惑。

提问前先自行反思和研究。主动探索代码库，调研业界标准实践和常规模式。不要问那些已有明显答案的蠢问题。你给我的选项必须是经过你仔细考虑和事实核查的、可行且周全的选项。
